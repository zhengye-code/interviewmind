# 2. 三个要先想明白的点

## 2.1 什么叫"幂等落库"

`generate` 可能被调用两次（前端重试、用户连点）。我们希望：

```
第 1 次：库里 0 条 → 调 AI（37 秒）→ 存 10 条 → 返回 10 条
第 2 次：库里 10 条 → 不调 AI（0 秒）→ 直接返回 10 条
```

**关键**：第 2 次要能从数据库里读出题目、还原成和第一次一样的返回结构。

所以 `toResponses` 必须能从"数据库实体"拼出完整 DTO —— 包括 `categoryLabel`（数据库里只存了 `categoryKey`）。

`categoryLabel` 从哪来？从 `plan_json` 里查（那份配额单里有 `categoryKey` 和 `label` 的对应关系）。这就是 `toResponses` 要多传一个 `plan` 参数的原因。

## 2.2 为什么要"校准总题数"

`interview_sessions.total_questions` 是创建会话时定下的（比如 10）。

但 AI 是概率性的，可能只给 8 道。如果我们坚持"必须是 10 道"，就只能报错让用户重试。

本步的选择是：**以实际拿到的题数为准**。

```
会话里写 total_questions = 10
AI 实际给了 8 道
→ 把 total_questions 改成 8
→ 这场面试就考 8 道
```

为什么要改？因为 `total_questions` 会被两个地方用到：

1. 前端进度条："第 3/10 题"
2. M5-2 的答题接口：判断"是不是最后一题了"

如果 `total_questions` 是 10 但库里只有 8 行，答题到第 8 题时程序会去找第 9 题 → 找不到 → 报错。

**一句话：两个数字必须一致，不一致就改那个可以改的。**

## 2.3 为什么写库要单独一个类

这是本步唯一容易卡住的地方。

**背景**：Spring 的 `@Transactional` 是靠"代理对象"生效的。

```
外部调用 A.方法() → 【代理：开事务】→ 真正的方法 → 【提交】
```

**坑 1：自己调自己不走代理**

如果 `InterviewQuestionService` 里写：

```java
public void generate() {
    this.saveAll(entities);   // 自己调自己，@Transactional 无效
}

@Transactional
public void saveAll(...) { ... }
```

`@Transactional` 完全不起作用，10 条题可能只写进去一部分。

**坑 2：在事务里 catch 唯一约束异常会导致后续查询报错**

```java
@Transactional
public void generate() {
    try {
        questionRepo.saveAll(list);      // 抛 DataIntegrityViolationException
    } catch (Exception e) {
        questionRepo.findAll();          // ← 这里会抛 UnexpectedRollbackException
    }
}
```

原因：异常一抛，Hibernate 就把事务标记成"必须回滚"。你虽然 catch 了，事务已经脏了。

**解决办法**：把写库放到**另一个类**里，让事务边界停在那个类上。这样主厨在**事务外面** catch，就完全没问题。

```
InterviewQuestionService.generate()        ← 没有事务，在"外面"
    └→ InterviewQuestionPersister.saveAll()  ← 有事务，边界在这里
        （如果它抛异常，事务已经干净地回滚了，外层可以放心 catch）
```

## 3.3 校对员（简版）

`src/main/java/com/interviewmind/modules/interview/service/QuestionBatchSanitizer.java`

```java
package com.interviewmind.modules.interview.service;

import com.interviewmind.modules.interview.model.CategoryQuota;
import com.interviewmind.modules.interview.model.GeneratedQuestion;
import org.springframework.stereotype.Component;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Locale;
import java.util.Map;
import java.util.Set;
import java.util.regex.Pattern;

/**
 * 校对员（简版）：把 AI 的原始输出洗干净，合并进"已选好的题目"里。
 *
 * 只做三件事：
 *   1. 丢掉空题、丢掉自创分类
 *   2. 去掉重复题（包括和已选题目重复）
 *   3. 每个分类不超过配额，答案要点最多 5 条
 *
 * 注意：简版不做"补题"。数量不够时由 InterviewQuestionService 校准总题数。
 */
@Component
public class QuestionBatchSanitizer {

    private static final int MAX_EXPECTED_POINTS = 5;

    /** 判重时忽略的字符：空白、英文标点、中文标点 */
    private static final Pattern NOISE =
            Pattern.compile("[\\s\\p{Punct}，。？！；：、“”‘’（）《》、·…—－]");

    public List<GeneratedQuestion> merge(List<GeneratedQuestion> selected,
                                         List<GeneratedQuestion> raw,
                                         List<CategoryQuota> plan) {

        List<GeneratedQuestion> result = new ArrayList<>(selected == null ? List.of() : selected);

        Map<String, Integer> quotas = new HashMap<>();
        for (CategoryQuota quota : plan) {
            quotas.put(quota.categoryKey(), quota.quota());
        }
        if (quotas.isEmpty()) {
            return result;
        }

        // 统计已选题目：每类几道、每道题长什么样
        Map<String, Integer> accepted = new HashMap<>();
        Set<String> seen = new HashSet<>();
        for (GeneratedQuestion question : result) {
            accepted.merge(question.categoryKey(), 1, Integer::sum);
            seen.add(normalizeText(question.question()));
        }

        if (raw == null) {
            return result;
        }

        for (GeneratedQuestion question : raw) {
            if (question == null || question.question() == null || question.question().isBlank()) {
                continue;
            }

            String categoryKey = normalizeKey(question.categoryKey());
            if (categoryKey == null || !quotas.containsKey(categoryKey)) {
                continue;
            }

            if (accepted.getOrDefault(categoryKey, 0) >= quotas.get(categoryKey)) {
                continue;
            }

            String normalized = normalizeText(question.question());
            if (normalized.isEmpty() || !seen.add(normalized)) {
                continue;
            }

            accepted.merge(categoryKey, 1, Integer::sum);
            result.add(new GeneratedQuestion(
                    question.question().trim(),
                    categoryKey,
                    capExpectedPoints(question.expectedPoints())));
        }
        return result;
    }

    private List<String> capExpectedPoints(List<String> points) {
        if (points == null || points.isEmpty()) {
            return List.of();
        }
        List<String> cleaned = new ArrayList<>();
        for (String point : points) {
            if (point == null || point.isBlank()) {
                continue;
            }
            cleaned.add(point.trim());
            if (cleaned.size() >= MAX_EXPECTED_POINTS) {
                break;
            }
        }
        return List.copyOf(cleaned);
    }

    private String normalizeKey(String key) {
        if (key == null || key.isBlank()) {
            return null;
        }
        return key.trim().toUpperCase(Locale.ROOT);
    }

    private String normalizeText(String text) {
        if (text == null) {
            return "";
        }
        return NOISE.matcher(text.toLowerCase(Locale.ROOT)).replaceAll("");
    }
}
```

> ⚠️ 注意 `new GeneratedQuestion(...)` 的参数顺序。
> 你现在的 record 定义是 `GeneratedQuestion(String question, String categoryKey, List<String> expectedPoints)` ——
> **`question` 在前，`categoryKey` 在后**。写反了编译器不会报错（两个都是 `String`），但数据会错位。
> 这是本步最容易犯的错。

```java
package com.interviewmind.modules.interview.service;

import com.interviewmind.modules.interview.model.InterviewQuestionEntity;
import com.interviewmind.modules.interview.repository.InterviewQuestionRepository;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

/**
 * 只做一件事：在一个事务里把题目写进数据库。
 *
 * 为什么单独一个类？见 2.3：
 *   @Transactional 靠代理生效，同类内部自调用会绕过代理；
 *   而调用方需要在事务外面 catch 唯一约束冲突，所以事务边界必须停在这个类的边界上。
 */
@Component
@RequiredArgsConstructor
public class InterviewQuestionPersister {

    private final InterviewQuestionRepository questionRepo;

    @Transactional
    public List<InterviewQuestionEntity> saveAll(List<InterviewQuestionEntity> questions) {
        return questionRepo.saveAll(questions);
    }
}
```

```java
package com.interviewmind.modules.interview.service;

import com.interviewmind.common.exception.BusinessException;
import com.interviewmind.common.exception.ErrorCode;
import com.interviewmind.modules.interview.model.CategoryQuota;
import com.interviewmind.modules.interview.model.GeneratedQuestion;
import com.interviewmind.modules.interview.model.InterviewDifficulty;
import com.interviewmind.modules.interview.model.InterviewQuestionEntity;
import com.interviewmind.modules.interview.model.InterviewSessionEntity;
import com.interviewmind.modules.interview.model.InterviewSessionStatus;
import com.interviewmind.modules.interview.model.QuestionResponse;
import com.interviewmind.modules.interview.repository.InterviewQuestionRepository;
import com.interviewmind.modules.interview.repository.InterviewSessionRepository;
import com.interviewmind.modules.interview.model.SkillDefinition;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import tools.jackson.core.JacksonException;
import tools.jackson.core.type.TypeReference;
import tools.jackson.databind.ObjectMapper;

import java.time.LocalDateTime;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

@Slf4j
@Service
@RequiredArgsConstructor
public class InterviewQuestionService {

    private final InterviewSessionRepository sessionRepo;
    private final InterviewQuestionRepository questionRepo;
    private final InterviewSkillService skillService;
    private final QuestionGenerateService generateService;
    private final QuestionBatchSanitizer sanitizer;
    private final InterviewQuestionPersister persister;
    private final ObjectMapper objectMapper;

    /**
     * 出题并落库。
     * 幂等：已经有题就直接返回，不重复调 AI（那一次要 30 多秒）。
     *
     * 注意：这个方法故意不加 @Transactional。
     * 它里面有一次十几秒的 AI 调用，如果包在事务里，会一直占着一个数据库连接不放。
     * 真正需要事务的只有最后那次写入，交给 InterviewQuestionPersister。
     */
    public List<QuestionResponse> generate(Long sessionId) {
        InterviewSessionEntity session = loadSession(sessionId);

        if (session.getStatus() != InterviewSessionStatus.IN_PROGRESS) {
            throw new BusinessException(ErrorCode.INTERVIEW_SESSION_STATE_INVALID,
                    "会话状态为 " + session.getStatus() + "，无法出题");
        }

        List<CategoryQuota> plan = parsePlan(session.getPlanJson());
        if (plan.isEmpty()) {
            throw new BusinessException(ErrorCode.INTERVIEW_QUESTION_GENERATION_FAILED,
                    "会话缺少出题配额，无法生成题目");
        }

        // 幂等：已经有题就跳过 AI
        List<InterviewQuestionEntity> existing =
                questionRepo.findBySessionIdOrderByQuestionIndexAsc(sessionId);
        if (!existing.isEmpty()) {
            log.info("会话已有 {} 道题，跳过出题: sessionId={}", existing.size(), sessionId);
            return toResponses(existing, plan);
        }

        SkillDefinition skill = skillService.getSkillDefinition(session.getSkillId());
        String systemPrompt = skillService.getSkillBodies(session.getSkillId());

        log.info("开始出题: sessionId={}, skill={}, 题量={}, 难度={}",
                sessionId, session.getSkillId(), session.getTotalQuestions(), session.getDifficulty());

        List<GeneratedQuestion> raw = generateService.generate(
                systemPrompt,
                skill.getDisplayName(),
                session.getDifficulty(),
                session.getTotalQuestions(),
                plan,
                "");

        List<GeneratedQuestion> cleaned = sanitizer.merge(List.of(), raw, plan);
        if (cleaned.isEmpty()) {
            throw new BusinessException(ErrorCode.INTERVIEW_QUESTION_GENERATION_FAILED,
                    "AI 没有返回可用的题目");
        }

        // 校准：以实际拿到的题数为准，避免"会话说 10 题、库里只有 8 题"
        if (cleaned.size() != session.getTotalQuestions()) {
            log.warn("AI 实际给出 {} 道，计划 {} 道，以实际为准: sessionId={}",
                    cleaned.size(), session.getTotalQuestions(), sessionId);
            session.setTotalQuestions(cleaned.size());
            sessionRepo.save(session);
        }

        List<InterviewQuestionEntity> entities =
                buildEntities(sessionId, cleaned, session.getDifficulty());

        try {
            log.info("题目已生成 {} 道: sessionId={}", entities.size(), sessionId);
            return toResponses(persister.saveAll(entities), plan);
        } catch (DataIntegrityViolationException e) {
            // 并发出题：另一个请求抢先写进去了，把它的结果返回即可
            log.warn("并发出题冲突，返回已写入的题目: sessionId={}", sessionId);
            return toResponses(
                    questionRepo.findBySessionIdOrderByQuestionIndexAsc(sessionId), plan);
        }
    }

    @Transactional(readOnly = true)
    public List<QuestionResponse> getQuestions(Long sessionId) {
        InterviewSessionEntity session = loadSession(sessionId);
        return toResponses(
                questionRepo.findBySessionIdOrderByQuestionIndexAsc(sessionId),
                parsePlan(session.getPlanJson()));
    }

    private InterviewSessionEntity loadSession(Long sessionId) {
        return sessionRepo.findById(sessionId)
                .orElseThrow(() -> new BusinessException(
                        ErrorCode.INTERVIEW_SESSION_NOT_FOUND, "面试会话不存在,id=" + sessionId));
    }

    /** 把 AI 给的题目变成要写进数据库的行 */
    private List<InterviewQuestionEntity> buildEntities(Long sessionId,
                                                        List<GeneratedQuestion> collected,
                                                        InterviewDifficulty difficulty) {
        List<InterviewQuestionEntity> entities = new ArrayList<>(collected.size());
        LocalDateTime now = LocalDateTime.now();
        for (int index = 0; index < collected.size(); index++) {
            GeneratedQuestion generated = collected.get(index);
            InterviewQuestionEntity entity = new InterviewQuestionEntity();
            entity.setSessionId(sessionId);
            entity.setQuestionIndex(index);
            entity.setCategoryKey(generated.categoryKey());
            entity.setDifficulty(difficulty);
            entity.setQuestionText(generated.question());
            entity.setExpectedPoints(toJson(generated.expectedPoints()));
            // 只有第 0 题算"已经问出来了"，其余等用户答到那一题时再打时间戳
            if (index == 0) {
                entity.setAskedAt(now);
            }
            entities.add(entity);
        }
        return entities;
    }

    /** 实体 → DTO。categoryLabel 从 quota 单里查，数据库里只存了 categoryKey */
    private List<QuestionResponse> toResponses(List<InterviewQuestionEntity> entities,
                                               List<CategoryQuota> plan) {
        Map<String, String> labels = new HashMap<>();
        for (CategoryQuota quota : plan) {
            labels.put(quota.categoryKey(), quota.label());
        }
        return entities.stream()
                .map(entity -> new QuestionResponse(
                        entity.getId(),
                        entity.getQuestionIndex(),
                        entity.getCategoryKey(),
                        labels.getOrDefault(entity.getCategoryKey(), entity.getCategoryKey()),
                        entity.getDifficulty() == null ? null : entity.getDifficulty().name(),
                        entity.getQuestionText()))
                .toList();
    }

    private List<CategoryQuota> parsePlan(String json) {
        if (json == null || json.isBlank()) {
            return List.of();
        }
        try {
            return objectMapper.readValue(json, new TypeReference<List<CategoryQuota>>() {
            });
        } catch (JacksonException e) {
            log.warn("解析出题配额失败: {}", json);
            return List.of();
        }
    }

    private String toJson(List<String> points) {
        try {
            return objectMapper.writeValueAsString(points == null ? List.of() : points);
        } catch (JacksonException e) {
            throw new BusinessException(ErrorCode.INTERVIEW_QUESTION_GENERATION_FAILED,
                    "答案要点序列化失败", e);
        }
    }
}
```

```java
package com.interviewmind.modules.interview.service;

import com.interviewmind.modules.interview.model.CategoryQuota;
import com.interviewmind.modules.interview.model.GeneratedQuestion;
import org.junit.jupiter.api.Test;

import java.util.List;

import static org.assertj.core.api.Assertions.assertThat;

class QuestionBatchSanitizerTest {

    private final QuestionBatchSanitizer sanitizer = new QuestionBatchSanitizer();

    private static List<CategoryQuota> plan() {
        return List.of(
                new CategoryQuota("JAVA", "Java", "CORE", 2),
                new CategoryQuota("MYSQL", "MySQL", "CORE", 1));
    }

    /** 注意参数顺序：question 在前，categoryKey 在后 */
    private static GeneratedQuestion q(String categoryKey, String question) {
        return new GeneratedQuestion(question, categoryKey, List.of("要点一"));
    }

    @Test
    void 自创分类会被丢弃() {
        List<GeneratedQuestion> result = sanitizer.merge(List.of(),
                List.of(q("JAVA", "HashMap 扩容机制"), q("GO", "goroutine 调度")),
                plan());

        assertThat(result).hasSize(1);
        assertThat(result.get(0).categoryKey()).isEqualTo("JAVA");
    }

    @Test
    void 超过配额的部分会被截断() {
        List<GeneratedQuestion> result = sanitizer.merge(List.of(),
                List.of(q("JAVA", "题一"), q("JAVA", "题二"), q("JAVA", "题三")),
                plan());

        assertThat(result).hasSize(2);
    }

    @Test
    void 完全相同的问题只保留一条() {
        List<GeneratedQuestion> result = sanitizer.merge(List.of(),
                List.of(q("JAVA", "HashMap 的扩容机制"), q("JAVA", "HashMap 的扩容机制")),
                plan());

        assertThat(result).hasSize(1);
    }

    @Test
    void 只差标点空白的问题也算重复() {
        List<GeneratedQuestion> result = sanitizer.merge(List.of(),
                List.of(q("JAVA", "HashMap 的扩容机制"), q("JAVA", "HashMap的扩容机制？")),
                plan());

        assertThat(result).hasSize(1);
    }

    @Test
    void 与已选题目重复时不会重复加入() {
        List<GeneratedQuestion> selected = List.of(q("JAVA", "HashMap 的扩容机制"));

        List<GeneratedQuestion> result = sanitizer.merge(selected,
                List.of(q("JAVA", "HashMap 的扩容机制"), q("JAVA", "ConcurrentHashMap 的分段锁")),
                plan());

        assertThat(result).hasSize(2);
    }

    @Test
    void 分类标识大小写会被归一化() {
        List<GeneratedQuestion> result = sanitizer.merge(List.of(),
                List.of(q("java", "HashMap 的扩容机制")),
                plan());

        assertThat(result).hasSize(1);
        assertThat(result.get(0).categoryKey()).isEqualTo("JAVA");
    }

    @Test
    void 空题目与空要点会被清洗() {
        List<GeneratedQuestion> result = sanitizer.merge(List.of(),
                List.of(new GeneratedQuestion("   ", "JAVA", List.of("x")),
                        new GeneratedQuestion("HashMap 的扩容机制", "JAVA", null)),
                plan());

        assertThat(result).hasSize(1);
        assertThat(result.get(0).expectedPoints()).isEmpty();
    }

    @Test
    void 答案要点最多保留五条() {
        List<String> points = List.of("1", "2", "3", "4", "5", "6", "7");

        List<GeneratedQuestion> result = sanitizer.merge(List.of(),
                List.of(new GeneratedQuestion("HashMap 的扩容机制", "JAVA", points)),
                plan());

        assertThat(result.get(0).expectedPoints()).hasSize(5);
    }
```

# 5. 常见错误

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 题目文字串到分类里 | `new GeneratedQuestion(...)` 参数顺序写反了 | 顺序是 `(question, categoryKey, expectedPoints)` |
| 出题 3005：`AI 没有返回可用的题` | 8 道全被判成重复或分类不对 | 看日志里 AI 返回了几道 |
| 第二次调还是很慢 | 幂等没生效 | 检查 `findBySessionIdOrderByQuestionIndexAsc` 是否真查到（打印一下 size） |
| `total_questions` 和实际题数不一致 | 校准那段没执行 | 检查是否在 `save` 之前就 return 了 |
| 唯一约束冲突报 500 | catch 的位置不在事务外面 | 确认 `saveAllQuestions` 在 `InterviewQuestionPersister` 里 |
| `UnexpectedRollbackException` | 在事务内 catch 了数据库异常 | 同上，事务边界必须在另一个类 |
| 返回里 `categoryLabel` 是 `JAVA` 而不是 `Java` | `toResponses` 没收到 `plan` | 检查是否把 `parsePlan` 的结果传进去了 |
| 编译报 `QuestionResponse` 构造器参数不匹配 | 改了字段名但没改 `new QuestionResponse(...)` | 检查 `toResponses` |
